# LifeLine

LifeLine is a Python group project for 95-895 Python Systems Fundamentals.

## Project structure

```text
LifeLine/
├── models.py       # domain classes and custom exceptions
├── demo.py         # runs the M1 demonstration
├── README.md       # run instructions, concept map, and contributions
└── station.json    # generated by demo.py
```

## How to run

From the project directory:

```bash
python demo.py
```

The demo will be completed as part of M1.
